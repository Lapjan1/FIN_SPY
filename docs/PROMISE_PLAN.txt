ARCHITECTURE (confirmed, keep it)
Extractor -> normalized OLTP DB -> representation builders read ONLY the
DB -> stateless download serving. Tables are normalized (tenants, docs,
txns, spans, classifications, accounts, journal entries/lines, flags,
audit); star-schema VIEWS serve PowerBI. Nothing builds reports from raw
extraction output. Rule for this plan: downloads regenerate bytes on each
request and stream them (FileResponse); nothing report-like persists on
the ephemeral disk. The vault alone lives on the Railway volume.

D8 Delete the report-job queue path; every kind generates synchronously
